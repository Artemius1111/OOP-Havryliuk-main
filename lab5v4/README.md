# Лабораторна робота №5: Поліморфізм
**Тема:** Поліморфізм: динамічне зв’язування та перевизначення методів  
**Мета:** Навчитися реалізовувати поліморфну поведінку за допомогою віртуальних методів та їх
перевизначення, а також агрегувати результати поліморфних викликів.

## Опис ієрархії класів
* **Device** (базовий клас) — містить властивість `Brand` та віртуальний метод `virtual PerformAction()`.
* **Printer** (похідний) — додає `PagesPerMinute` та перевизначає `PerformAction()`.
* **Scanner** (похідний) — додає `DPI` та перевизначає `PerformAction()`.
* **Monitor** (похідний) — додає `ScreenSize` та перевизначає `PerformAction()`.

## Хід роботи 
Я створив консольний проєкт lab5v4. Реалізував базовий клас Device з віртуальним методом PerformAction() та похідні класи Printer, Scanner і Monitor із його перевизначенням (override). У Program створив колекцію List<Device>, у циклі продемонстрував динамічне зв’язування, заагрегував результати дій у список actionLog і вивів звіт у консоль. Наостанок оформив README.md та завантажив проєкт на GitHub за допомогою git add, git commit і git push.
