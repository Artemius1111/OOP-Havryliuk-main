# Лабораторна робота №6: Наслідування. Ключові слова base, override, virtual.
**Тема:** Наслідування. Ключові слова base, override, virtual. Приховування членів (new).  
**Мета:** Навчитися створювати ієрархії класів, використовувати ключові слова base, virtual, override для реалізації поліморфізму, а також розуміти відмінності між override та приховуванням членів за допомогою new.  

---

## Хід роботи

У ході виконання роботи було створено консольний проєкт у директорії OOP-Havryliuk/lab6v4 за допомогою .NET CLI. 

У проєкті реалізовано ієрархію класів Animal -> Dog -> Cat. Базовий клас Animal містить приватні поля name та age, відповідні публічні властивості, конструктор, віртуальний метод MakeSound() та невіртуальний метод GetSpecies().

Похідні класи Dog та Cat успадковують клас Animal та передають параметри базовому конструктору через синтаксис : base(name, age). Клас Dog додає властивість Breed та унікальний метод Fetch(), а клас Cat додає властивість IsIndoor та унікальний метод Purr(). Обидва похідні класи перевизначають віртуальний метод MakeSound() за допомогою ключового слова override. Для демонстрації приховування членів у класі Dog створено метод GetSpecies() із модифікатором new, який приховує однойменний метод базового класу.

У методі Main класу Program створено екземпляри класів Dog та Cat, викликано їхні власні методи, а також продемонстровано поліморфізм через масив посилань типу Animal[]. Окремо продемонстровано різницю між override та new: виклик прихованого методу GetSpecies() залежить від типу посилання (Dog або Animal), тоді як перевизначений метод MakeSound() завжди викликає реалізацію конкретного об'єкта.

## Відповіді на контрольні питання

**Поясніть принцип наслідування в ООП. Наведіть приклад з реального світу.** Наслідування дозволяє похідному класу успадковувати стан і поведінку базового класу за схемою «є-різновидом» (наприклад, Dog є різновидом Animal), що запобігає дублюванню коду та дозволяє будувати ієрархії об'єктів.

**Для чого використовується ключове слово base? Наведіть приклади його застосування.** Застосовується для звернення до елементів базового класу з похідного — найчастіше для виклику конструктора базового класу (: base(name, age)) або для викликання базової реалізації методу (base.MakeSound()).

**У чому полягає різниця між virtual та override? Як вони забезпечують поліморфізм?** virtual у базовому класі дозволяє перевизначення методу, а override у похідному класі надає його нову реалізацію. Вони забезпечують поліморфізм, оскільки викликаний метод визначається фактичним типом об'єкта в пам'яті під час виконання програми.

**Коли варто використовувати модифікатор new для приховування члена базового класу, і які наслідки це має?** Модифікатор new використовується для явного приховування невіртуального члена базового класу. На відміну від override, виклик методу з new розриває поліморфний зв'язок і залежить від типу посилання, а не від типу створимого об'єкта.
