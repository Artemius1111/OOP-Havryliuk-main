# Лабораторна робота №11: LINQ: SelectMany, пагінація й custom extensions.

**Тема:** LINQ: SelectMany, пагінація й custom extensions.

**Мета:** Навчитися використовувати оператор SelectMany для роботи з вкладеними колекціями, реалізовувати пагінацію даних за допомогою LINQ, а також створювати власні методи розширення.


## Хід роботи

За допомогою .NET CLI створено консольний проєкт lab11v4 у директорії OOP-Havryliuk.

Створено класи сутностей Company (компанія зі списком співробітників), Employee (співробітник зі списком проєктів) і Project (проєкт). Заповнено тестові дані: 10 компаній, 22 співробітники і 12 проєктів.

За допомогою SelectMany отримано всі проєкти всіх співробітників усіх компаній в одному списку. Реалізовано пагінацію компаній по 2 на сторінку за допомогою Skip і Take та виведено всі сторінки поспіль. Створено метод розширення TotalEmployees, який рахує загальну кількість співробітників у наборі компаній, і показано його роботу для всіх компаній, для однієї сторінки та для відфільтрованих компаній.

## Відповіді на контрольні питання

* **Для чого використовується SelectMany? Чим він відрізняється від Select?**
  SelectMany розгортає вкладені колекції в один плоский список. Select для 10 компаній поверне 10 списків співробітників, а SelectMany поверне одразу всіх 22 співробітників одним списком.

* **Як реалізувати пагінацію за допомогою LINQ?**
  За допомогою методів Skip і Take: Skip пропускає елементи попередніх сторінок, а Take бере потрібну кількість елементів для поточної сторінки.

* **Що таке методи розширення і як вони пов'язані з LINQ?**
  Метод розширення дозволяє додати новий метод до існуючого типу, не змінюючи його код. Він оголошується в статичному класі як статичний метод з this перед першим параметром. Усі методи LINQ (Where, Select, Skip тощо) — це методи розширення для IEnumerable.

* **Приклад власного методу розширення для IEnumerable.**
  У цій роботі це TotalEmployees для колекції компаній: він сумує кількість співробітників у кожній компанії. Також створено метод Page, який повертає потрібну сторінку будь-якої колекції.
